Rules draft

Variant status: House-rule version needed. Recommended direction: simplified non-gambling version with a printable betting mat.

Object

Use fake chips to make predictions about the dice roll. The goal can be most chips after a set number of rounds.

Beginner bets to include

A simplified version should probably include only:

  • Big / small total
  • Odd / even total
  • Specific number appears
  • Exact total
  • Any triple
  • Specific double

Why it works

Sic Bo gives a casino-night option besides Craps. It should be kept simple so it feels like a party game instead of a math chart.
