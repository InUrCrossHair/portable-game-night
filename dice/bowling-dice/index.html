Rules

Object

Play 10 bowling frames using dice as pins knocked down.

Setup

Use 10 dice if you have them. If not, use 5 dice and roll twice per ball, counting successes.

How to play

  1. For each ball, roll the available dice. Each die showing 4, 5, or 6 knocks down one pin.
  2. Frame 1 ball: roll up to 10 dice. Count knocked pins. Remove those dice.
  3. If pins remain, roll the remaining dice for ball 2.
  4. Strike if all 10 pins fall on ball 1. Spare if all 10 fall by ball 2.

Scoring

Score like bowling if you know standard bowling scoring, or simply total pins knocked down over 10 frames for a quick version.
