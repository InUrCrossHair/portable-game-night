Rules

Object

Bet on which number will appear when three dice are rolled.

Setup

Use 3 dice, tokens, and a simple betting area numbered 1 through 6.

How to play

  1. Players place tokens on any number from 1 to 6.
  2. Roll all 3 dice.
  3. A bet wins if the chosen number appears on at least one die.

Recommended payouts

  • Number appears once: win 1 token per token bet.
  • Number appears twice: win 2 tokens per token bet.
  • Number appears three times: win 3 tokens per token bet.

House note

These even payouts are simple and party-friendly, not casino-accurate. The goal is a fun token game, not a math lecture.
