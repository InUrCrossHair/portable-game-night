Rules draft

Variant status: House-rule version needed. Recommended direction: non-gambling points version with one clean ranking chart.

Object

Win rounds by rolling the highest-ranked result. Play to a set number of round wins or points.

Common ranking idea

A clean casual version could use:

  1. 4-5-6 = automatic high result
  2. Triples, ranked 6-6-6 down to 1-1-1
  3. Pairs, where the odd die becomes the point
  4. 1-2-3 = automatic low result
  5. Unmatched rolls are rerolled

Why it works

Cee-lo creates quick drama because some rolls are instantly great or instantly terrible. It needs a locked ranking chart so the rules do not get messy.
