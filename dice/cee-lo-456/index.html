Rules draft

Variant status: Ready. Uses a non-gambling round-win version with a clean ranking chart.

Object

Be the first player to win 5 rounds.

How a turn works

  1. Each player rolls 3 dice.
  2. If the roll produces a ranked result, keep it.
  3. If the roll is unranked, reroll.
  4. You get a maximum of 3 attempts to produce a ranked result.
  5. If you have no ranked result after 3 attempts, your result is a bust.

Ranking, highest to lowest

  1. 4-5-6 = automatic best result
  2. Triples, ranked 6-6-6 down to 1-1-1
  3. Point rolls, which are a pair plus a third die. The odd die is your point.
  4. Bust, which means no pair, no triple, and no 4-5-6 after 3 attempts.
  5. 1-2-3 = automatic worst result

Comparing point rolls

Higher point wins.

Example:


2-2-6 beats 5-5-4

The first roll has a point of 6. The second has a point of 4.

Ties

Tied players reroll.

Why it works

Cee-lo creates quick drama because some rolls are instantly great or instantly terrible. This version keeps the dramatic identity of Cee-lo but avoids gambling and regional weirdness.
