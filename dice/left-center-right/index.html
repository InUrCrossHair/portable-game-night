Rules draft

Variant status: House-rule version needed. Recommended direction: standard d6 mapping so no specialty dice are needed.

Object

Be the last player with tokens remaining.

Simple d6 mapping

  • 1 = pass one token left
  • 2 = pass one token right
  • 3 = put one token in the center
  • 4, 5, 6 = keep token

How a turn works

  1. Each player starts with 3 tokens.
  2. On your turn, roll up to 3 dice, but never more dice than tokens you have.
  3. Resolve each die using the mapping above.
  4. If you have no tokens, you skip your turn unless tokens are passed back to you later.

Why it works

This is not strategic, but it is one of the easiest possible group games to run with normal dice and tokens.
