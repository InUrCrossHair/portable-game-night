Rules

Variant status: Ready. Uses a standard d6 mapping so no specialty dice are needed.

Object

Be the last player with tokens.

Setup

Each player starts with 3 tokens.

Dice mapping

  • 1 = pass one token left
  • 2 = pass one token right
  • 3 = put one token in the center
  • 4, 5, 6 = keep token

How a turn works

  1. On your turn, roll up to 3 dice.
  2. Roll one die for each token you have, up to a maximum of 3 dice.
  3. Resolve each die using the mapping above.
  4. If you have no tokens, you skip your turn, but you can re-enter if someone passes you tokens.

End of game

When only one player has tokens, that player wins.

Why it works

This duplicates the basic feel of commercial LCR using normal dice. It is intentionally almost pure luck, which makes it better as a filler than as a strategy game.
