Rules

Portable betting note

Use candy, coins, chips, or any harmless tokens. Agree before starting that tokens are for scorekeeping or snacks, not real-money stakes.

Object

Make the best 5-card poker hand or win the pot when everyone else folds.

Setup

  • Each player antes one token. Deal 5 cards face down to each player.

How to play

  1. First betting round: check, bet, call, raise, or fold using simple table limits.
  2. Each remaining player may discard 0–3 cards and draw replacements. Allow 4 cards only if the player shows an ace, if you want that common house rule.
  3. Second betting round. Then remaining players reveal hands. Best poker hand wins the pot.

Recommended limit

Use a simple limit: one token ante, one-token bets, and at most three raises per betting round.
