Rules

Object

Win at least one trick each hand to stay in the game.

Setup

  • Deal 7 cards to each player for the first hand. Turn one card from the deck to set trump.
  • For each next hand, deal one fewer card: 6, 5, 4, and so on.

How to play

  1. Player left of dealer leads. Follow suit if able.
  2. Highest trump wins the trick; if no trump is played, highest card of the led suit wins.
  3. The winner of each trick leads the next trick.

Elimination

Any player who takes zero tricks in a hand is knocked out. Last player remaining wins.

Gentler party variant

Instead of elimination, give a letter or lose a token for taking zero tricks. That keeps everyone at the table longer.
