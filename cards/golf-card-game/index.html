Rules

Object

Finish with the lowest score after a set number of rounds.

Setup

For 6-card Golf, deal each player 6 cards face down in a 2 by 3 grid. Each player flips any two cards face up.

How to play

  1. Draw from the deck or discard pile.
  2. Replace one card in your grid or discard the drawn card.
  3. When one player has all cards face up, everyone else gets one more turn.

Starter scoring

Aces = 1, numbers = face value, jacks/queens = 10, kings = 0. Matching cards in a column cancel to 0.
